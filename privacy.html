Fucina rclone - privacy policy

Last updated: 2026-10-27

Who uses the application

Fucina rclone is used only by its owner, on the owner's own Google account. It is not offered to other people.

What data it accesses

The application requests the Google Drive scope https://www.googleapis.com/auth/drive.file. With it, the application can create files in the owner's Drive and read, change or delete only the files it created. It cannot see any other file in the Drive, nor Gmail, contacts or other Google data.

How the data is used

The files are results of engineering calculations, copied from the owner's compute server to the owner's Drive. They are used only by the owner.

Where the data is stored

The files stay in the owner's Google Drive. The OAuth token is stored only on the owner's compute server, readable only by the service that uses it.

Sharing

No data is sold, shared with third parties, used for advertising or used to train models.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The files created by the application can be deleted from Google Drive like any other file.
