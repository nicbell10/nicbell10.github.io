Fucina rclone

Fucina rclone is a private, single-user application. It lets the owner's own compute server copy the results of engineering calculations into a folder of the owner's own Google Drive, using rclone.

  • It is not offered to the public and has no other users.
  • It asks only for the drive.file scope: it can see and change only the files it creates itself, not the rest of the Drive.
  • It does not show ads, sell data or share data with anyone.
